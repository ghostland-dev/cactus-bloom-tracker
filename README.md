# Cactus Bloom Tracker

Track cactus collections and flowering events.

## Features

- Plant collection
- Bloom history

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/cactus-bloom-tracker.git
cd cactus-bloom-tracker
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
